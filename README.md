# 🛒 Análise de Cesta de Compras com Apriori

Este projeto implementa o **Algoritmo Apriori** para identificar **itemsets frequentes** e gerar **regras de associação** a partir de dados transacionais utilizando **Python**, **Pandas** e **MLxtend**.

## 🚀 Tecnologias

* 🐍 Python
* 🐼 Pandas
* 📈 MLxtend

## ⚙️ Funcionalidades

* 📂 Leitura de transações em arquivo `.txt`
* 🔄 Codificação com `TransactionEncoder`
* 📊 Descoberta de itemsets frequentes com Apriori
* 🔗 Geração de regras de associação por confiança (*confidence*)

## ▶️ Como executar

Instale as dependências:

```bash
pip install pandas mlxtend
```

Execute o projeto:

```bash
python apriori.py
```
